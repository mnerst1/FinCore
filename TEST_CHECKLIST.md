# FinCore · ручная проверка

Проверяйте в отдельном профиле, чтобы сохранить демо. Суммы ниже — в выбранной основной валюте.

## Первый запуск и auth

- [ ] Чистая установка: npm ci → generate → migrate → seed → dev.
- [ ] Демо-вход, выход и повторный вход; приватные API после выхода возвращают 401.
- [ ] Зарегистрировать новый email с паролем из 12+ символов.
- [ ] Дубликат email и неверный пароль дают понятную ошибку.
- [ ] После 10 попыток по одному email новые попытки ограничиваются на 15 минут.
- [ ] Изменить профиль; обновить страницу — значения сохранены.
- [ ] Сменить пароль; старый пароль и другие сеансы больше не работают.

## Основной учёт

- [ ] Создать счёт A с балансом 1000 и счёт B с балансом 0.
- [ ] Доход 200 в A → A=1200; расход 50 → A=1150.
- [ ] Перевод 100 A→B → A=1050, B=100, общая сумма=1150.
- [ ] Перевод между одинаковыми счетами отклоняется.
- [ ] Редактирование суммы меняет баланс; удаление отменяет влияние операции.
- [ ] Запись с будущей датой видна в списке и календаре, но не меняет сегодняшний баланс.
- [ ] Поиск по заметке/описанию; фильтры типа/счёта/категории/дат; все варианты сортировки.
- [ ] Неверная дата, отрицательная сумма, больше двух знаков после точки отклоняются.
- [ ] Счёт с операциями нельзя удалить.

## Бюджеты, цели и долги

- [ ] Создать категорию и подкатегорию; цикл в дереве не допускается.
- [ ] Бюджет 100 на текущий месяц; расход 90 в дочерней категории → 90% и напоминание.
- [ ] Расход 20 → превышение 10; изменить месяц → другой набор бюджетов.
- [ ] Цель 1000, выделено 250 → 25%; редактирование накоплений меняет прогресс.
- [ ] Накопления цели не увеличивают сумму счетов или чистый капитал.
- [ ] Долг «я должен» 100; погасить 30 со счёта A → долг 70, баланс A уменьшается на 30.
- [ ] Долг «мне должны» 100; получить 30 → долг 70, баланс A увеличивается на 30.
- [ ] Нельзя погасить больше остатка или поставить будущую дату погашения.
- [ ] Удалить операцию погашения → остаток долга и баланс восстановлены.
- [ ] После погашений нельзя вручную переопределить сумму долга, не удалив связанные платежи.

## Регулярные операции и календарь

- [ ] Создать регулярную операцию с сегодняшней датой; провести — появляется ровно одна запись.
- [ ] Повторное проведение и два одновременных запроса не создают дубликаты.
- [ ] Месячная дата 31 января переходит в конец февраля, затем в 31 марта.
- [ ] Выключить правило, убедиться, что оно не проводится.
- [ ] Ближайшие правила видны на overview; долги/цели/бюджеты формируют уведомления.
- [ ] «Прочитать все» сохраняет состояние после перезагрузки.
- [ ] Календарь переключает месяцы, показывает операции дня и открывает их редактор.

## Файлы и перенос

- [ ] Прикрепить PNG/JPEG/PDF через выбор и drag/drop; скачать исходные байты.
- [ ] TXT/HTML/SVG, неверная сигнатура и файл более 5 МБ отклоняются.
- [ ] Другой пользователь не может скачать/удалить вложение.
- [ ] Удаление чека удаляет запись и файл; удаление операции удаляет её чеки.
- [ ] Экспортировать CSV и JSON, проверить содержимое без паролей/сеансов.
- [ ] Импорт корректного CSV добавляет строки; импорт с ошибкой откатывается полностью.
- [ ] Повторный CSV импорт добавляет дубликаты — это явно указано.
- [ ] JSON восстановить в чистом профиле той же валюты; сверить балансы, категории, цели, долги, правила и содержимое чеков.
- [ ] Восстановление в профиль со счетами или другой валютой отклоняется.

- [ ] Пустой профиль, отсутствие результатов, skeleton загрузки и ошибка базы имеют понятные состояния.
- [ ] Графики соответствуют списку операций; доступны таблицы точных значений.
- [ ] История действий появляется после создания, изменения, удаления, импорта и погашения.
